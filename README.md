# XCLUDE Logistics Modules

**XCLUDE Logistics Modules** is an open-source repository designed to provide logistics and trade-related solutions for Odoo. This repository will streamline customs, shipping, and trade workflows. 

The first module, **Customs EORI Validation**, is focused on handling EORI (Economic Operators Registration and Identification) number validation to ensure compliance with European customs regulations.

## Modules

### **Customs EORI Validation**
The **Customs EORI Validation** module enables businesses to validate EU and UK (GB) EORI numbers directly in Odoo. This module ensures that all partner EORI numbers comply with customs regulations, making international trade operations smoother.

More modules will be added in the future, enhancing logistics, customs, and trade-related processes for Odoo and potentially other ERP systems.
